# 원내 PC 설치 안내

사회사업실 원스탑 서비스 · 효사랑가족요양병원 2병원 · 원큐사회사업실

---

## 먼저 알아두실 것

**설치할 프로그램은 Node.js 하나뿐입니다.** 그 외에는 아무것도 설치하지 않습니다. 인터넷이 안 되는 PC에서도 돌아갑니다.

**모든 자료는 이 PC 안에만 있습니다.** `data` 폴더의 `db.json` 파일 하나에 직원 명단, 봉사 내역, 신청 내역이 모두 들어 있습니다. 바깥으로 나가지 않습니다.

**비밀번호는 아무도 볼 수 없습니다.** 되돌릴 수 없는 형태로 저장되어, 담당자도 직원 비밀번호를 볼 수 없고 초기화만 할 수 있습니다.

---

# 1. 어떤 PC에 설치할까

| 조건 | 왜 |
|---|---|
| **항상 켜 둘 수 있는 PC** | 꺼지면 직원들이 접속하지 못합니다 |
| **병원 내부망에 연결된 PC** | 직원 휴대폰·PC가 같은 망에서 접속합니다 |
| **고정 IP를 받을 수 있는 PC** | IP가 바뀌면 주소가 바뀝니다 |

사회사업실 업무용 PC여도 됩니다. 다만 **절전 모드로 들어가면 접속이 끊기므로** 전원 설정에서 절전을 꺼 두세요.

> 제어판 → 전원 옵션 → 디스플레이는 꺼도 되지만 **컴퓨터는 절전 안 함**

---

# 2. Node.js 설치 (5분)

1. 다른 PC에서 <https://nodejs.org> 접속
2. **LTS** 라고 적힌 버튼 클릭 → 설치 파일(.msi) 내려받기
3. 그 파일을 USB로 옮겨 원내 PC에서 실행
4. 계속 [다음]을 눌러 설치 (기본값 그대로 두시면 됩니다)

설치가 끝나면 확인해 봅니다.

- 윈도우 키 + R → `cmd` 입력 → 엔터
- 검은 창에 `node -v` 입력 → 엔터
- `v20.…` 처럼 번호가 나오면 설치된 것입니다

---

# 3. 프로그램 올리기 (2분)

1. 받으신 폴더를 통째로 원내 PC에 복사합니다
2. 둘 자리를 정합니다 — `C:\원스탑서비스` 를 권합니다

> 바탕화면이나 다운로드 폴더는 실수로 지우기 쉽습니다. C 드라이브 바로 아래가 안전합니다.

폴더 안은 이렇게 생겼습니다.

```
원스탑서비스\
  시작.bat        ← 더블클릭하면 켜집니다
  백업.bat        ← 자료를 따로 복사해 둡니다
  server.js
  lib\
  public\
  data\           ← 처음 실행하면 생깁니다. 모든 자료가 여기에 있습니다
  설치안내.md
```

---

# 4. 처음 켜기 (3분)

**시작.bat** 을 더블클릭합니다.

검은 창이 열리고 이런 내용이 나오면 성공입니다.

```
  담당자 계정을 만들었습니다 →  아이디 admin / 비밀번호 1234
  첫 로그인에서 비밀번호를 반드시 바꿔 주세요.

═══════════════════════════════════════════════
  사회사업실 원스탑 서비스 — 켜졌습니다
═══════════════════════════════════════════════
  이 PC에서      http://localhost:3000
  다른 기기에서   http://192.168.0.15:3000
───────────────────────────────────────────────
```

**`다른 기기에서` 뒤에 나온 주소를 적어 두세요.** 직원들이 쓸 주소입니다. 숫자는 PC마다 다릅니다.

> 이 창을 닫으면 서비스가 꺼집니다. 최소화해 두세요.

**윈도우 방화벽 창이 뜨면 [액세스 허용]을 누르세요.** 이걸 막으면 다른 기기에서 접속할 수 없습니다.

# 5. 담당자 첫 설정 (10분)

브라우저를 열고 `http://localhost:3000` 으로 들어갑니다.

### ① 로그인하고 비밀번호 바꾸기

아이디 `admin`, 비밀번호 `1234`로 들어가면 바로 비밀번호 변경 화면이 나옵니다. **반드시 바꾸세요.** 기억하기 쉽고 남이 모를 것으로 정하시면 됩니다.

### ② 직원 명단 올리기

**직원 관리** 탭 → 파일 선택 → 엑셀 올리기

올리면 바로 반영되지 않고 **무엇이 바뀌는지 먼저 보여드립니다.** 확인하고 맨 아래 [명단에 반영]을 누르면 적용됩니다.

**부서 표기 점검**이 함께 나옵니다. `10병동` / `10W` / `10` 처럼 갈려 있으면 경고가 뜹니다. 이대로 두면 병동별 제한 인원이 작동하지 않으니 엑셀에서 고쳐서 다시 올려 주세요.

반영할 때 **계정이 함께 만들어지고, 임시 비밀번호 목록이 CSV로 내려받아집니다.** 이 파일을 열어 직원별로 번호를 알려주시면 됩니다.

### ③ 봉사 내역 올리기

**자료 관리** 탭 → 봉사 내역 엑셀 올리기. 올릴 때마다 전체가 교체됩니다.

### ④ 공고 등록하고 테스트

**모집 공고** 탭에서 하나 등록해 보고, 직원 계정으로 로그인해 신청까지 해 보세요.

# 6. 직원에게 알리기

### 주소 알려주기

4번에서 적어 둔 주소(`http://192.168.0.15:3000`)를 공지합니다.

**QR 코드를 만들어 붙이면 훨씬 편합니다.** 인터넷 되는 PC에서 QR 생성 사이트에 주소를 넣고 이미지를 받아 공지문에 넣으세요.

### 비밀번호 알려주기

②에서 받은 CSV 파일에 직원별 임시 비밀번호가 있습니다. **첫 로그인 때 본인이 직접 바꾸게 되어 있습니다.**

> 전체 공지에 비밀번호를 함께 적지 마세요. 개별로 전달하셔야 합니다.

### 안내문

받으신 `사용설명서_직원용.docx`를 인쇄해 병동에 돌리시면 됩니다.

# 8. 자동으로 켜지게 하기 (권장)

PC를 껐다 켜도 서비스가 저절로 올라오게 해 둡니다.

1. 윈도우 키 + R → `shell:startup` 입력 → 엔터
2. 열린 폴더에 **시작.bat 의 바로가기**를 만들어 넣습니다
   - 시작.bat 에서 마우스 오른쪽 → [바로 가기 만들기]
   - 만들어진 바로가기를 잘라내어 위 폴더에 붙여넣기

이제 PC가 켜질 때 자동으로 서비스가 뜹니다.

# 9. 문제가 생겼을 때

### 다른 기기에서 접속이 안 돼요

1. **서버 PC에서는 되나요?** `http://localhost:3000` 으로 확인
   - 여기도 안 되면 검은 창이 꺼져 있는 것입니다. 시작.bat 다시 실행
2. **같은 망인가요?** 직원 휴대폰이 병원 Wi-Fi에 연결돼 있어야 합니다
3. **방화벽** — 제어판 → Windows Defender 방화벽 → 앱 허용 → Node.js 체크 확인
4. **IP가 바뀌었나요?** 검은 창에 나오는 주소를 다시 확인해 보세요

### IP가 자꾸 바뀝니다

전산팀에 **고정 IP**를 요청하세요. 그게 어려우면 PC 이름으로 접속하는 방법도 있습니다 (`http://PC이름:3000`).

### 3000번이 이미 쓰이고 있대요

다른 번호로 바꿀 수 있습니다. 메모장으로 `시작.bat` 을 열고 `node server.js` 를 이렇게 고치세요.

```
set PORT=3100
node server.js
```

주소도 `:3100` 으로 바뀝니다.

### 직원이 비밀번호를 잊었대요

**직원 관리** 탭에서 그 직원의 [비번] 버튼 → 새 번호가 화면에 뜹니다 → 본인에게 알려주세요.

### 비밀번호를 5번 틀려 잠겼대요

10분 뒤에 저절로 풀립니다. 급하면 [비번]으로 초기화하시면 바로 풀립니다.

### 담당자 비밀번호를 잊었어요

되살릴 방법이 없습니다. 다만 `data\db.json` 을 메모장으로 열어 `"admins"` 부분을 통째로 `"admins": [],` 로 바꾸고 저장한 뒤 다시 켜면, `admin / 1234` 계정이 새로 만들어집니다. **직원 자료는 그대로 남습니다.**

### 자료가 날아간 것 같아요

`data\backup` 폴더에 날짜별 복사본이 있습니다.

1. 서비스를 끕니다 (검은 창에서 Ctrl + C)
2. `data\db.json` 의 이름을 `db-고장.json` 으로 바꿉니다
3. `data\backup` 에서 되살릴 날짜의 파일을 `data` 로 복사하고 이름을 `db.json` 으로 바꿉니다
4. 시작.bat 다시 실행

# 10. 알아두실 한계

**주소가 암호화되지 않습니다(HTTP).** 병원 내부망 안에서만 오가지만, 같은 망에 있는 다른 기기가 마음먹으면 들여다볼 수 있습니다. 전산팀에서 내부 인증서를 받을 수 있으면 HTTPS로 바꿀 수 있으니 문의해 보세요.

**이 PC가 꺼지면 서비스가 멈춥니다.** 자원봉사 모집은 한 달에 몇 번이라 치명적이지는 않지만, 모집 기간에는 PC를 켜 두셔야 합니다.

**관리할 사람이 분명해야 합니다.** 담당자가 바뀌면 이 문서와 담당자 계정을 함께 인계해 주세요.

# 자료가 어디 있는지

```
data\
  db.json           ← 모든 자료. 이 파일만 있으면 전부 복구됩니다
  backup\           ← 하루 한 번 자동 복사본 (30일치)
  log\              ← 날짜별 접속 기록
```

**db.json 하나만 챙기시면 됩니다.** 다른 PC에 옮겨도 그대로 이어집니다.
