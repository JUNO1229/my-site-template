# ResHub-C 운영 기준 (치료실 확인 사항 반영)

## 치료옵션
| 표시 | 의미 |
|---|---|
| (없음) | **J — 젬마치료 연계. 기본값이라 입력 시 생략** (옵션이 없으면 모두 J로 본다) |
| C | 쿠폰을 사용하는 치료 |
| S | 서비스로 하는 치료 |
| K | 미뤄뒀다가 받는 치료 |
| 기타 | 그 밖의 경우 (이전의 "무료" 포함) |

- 입력 화면에는 J 버튼이 없고 "기본(J)"이 기본 선택이다. CSV 가져오기·서버 저장 시 J는 자동으로 "없음"으로 통일된다.

## 치료실별 기준
| 치료실 | 동시 수용 | 1회 시간 | 시간대(타임) | 비고 |
|---|---|---|---|---|
| 고주파 | 항목별 1명 | 60분 | BSD 6 / EHY1 5 / EHY2 5 / 통원 4 | |
| 도수 | 1명 | 30분 | 10 | |
| 페인잼머 | 1명 | 30분 (40분 간격) | 8 | 30~40분 단위, 림프처럼 8타임 |
| 림프1 / 림프2 | 각 1명 | 60분 | 각 8 | |
| 파동 | **1명 (기기 1대)** | 50분 | 8 | 한 타임에 한 명 |
| 역박동 | 1명 | 40분 | 5 | 사용 재개. 현재 담당자 없음(담당자 지정 시 치료실 설정에서 입력) |

## 입력 규칙
- 같은 환자의 시간 겹침, 치료항목의 동시 수용 인원 초과는 서버가 거절한다. 예외 등록은 스케줄관리자·관리자만 가능.
- 상담실 입력 전 환자는 치료실에서 이름만 먼저 임시 등록하고, 환자명부에 등록되면 합쳐진다.

## 약식 표기 규칙 (확정)
- 압노바는 **압노 + 종류 + 단계**로 표기한다. 예) 압노바 Q 4단계 → `압노Q4` (종류 바로 뒤 숫자 = 단계). 횟수는 뒤에 붙인다: `압노Q4주2`.
