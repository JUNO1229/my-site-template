# 프로젝트 개요

## 배경
- 코어솔루션(IT·시스템·POS/키오스크 업체) / 모두패스(레저 지점). 모두의 플랫폼(시설운영)·모두의티켓 사업.
- 미아방지 서비스 신버전: 시설 방문 시 1회성 편의서비스. 고객이 QR 또는 발권키오스크에 보호자 연락처 입력 → QR이 손목밴드에 출력 → 발견자가 QR 스캔, 시설 관리자가 보안정보 입력 시 보호자 연락처 열람·통화. 일반 발견자에게는 관리자 연결 안내문구와 전화연결 기능만 제공(연락처 비노출).
- 영업 전략: 공원·다중 물놀이시설에 판매 제안 → 모두의 플랫폼 자연 소개 → 기관별 영업 포인트 발굴.

## 이 시스템의 목적
1. 전국 시설·기관 정보(주소·담당 부서·연락처) 수집
2. 필요도 판단(A/B/C)으로 우선순위 부여
3. 발송·영업 진행 관리(소개서/도입제안서 발송, 통화, 미팅, 파일럿)
4. 기관별 영업 포인트 축적(→ 모두의 플랫폼 연계 제안)
