# 연락처 보강

## 무엇이 빠져 있나
- 도시공원 데이터는 전화번호가 있으나 998건 공란. 기관 주소·담당자명 없음.
- 일반 테마파크 392곳 중 218곳, 허가 대형 55곳 중 14곳이 전화 공란(보강 후 허가 대형은 약 8곳 남음).

## 지금까지 시도한 방법과 결과
1. WebSearch: 미국 한정이고 결과가 제3자 여행·티켓 사이트 위주, 본문 스니펫 없음 → 연락처 신뢰도 낮음(third_party_recheck).
2. WebFetch: 허용 목록에 없는 도메인은 막힘. 제3자 사이트 일부는 번호를 반환.
3. 내장 브라우저(사이트별 접근 승인 필요): 공식 사이트 하단 푸터에서 번호 추출 성공(에버랜드, 롯데월드 부산, 하이원, 용평, 한화리조트, 오크밸리). 정규식 `\d{2,4}-\d{3,4}-?\d{0,4}|1[5-8]\d{2}-\d{4}`로 본문 스캔.
4. 실패 사례: 웰리힐리파크(개발자도구 감지 차단 — 우회하지 않음), 알펜시아·무주덕유산 접속 실패, 소노 푸터 미노출. docs data/manual/unresolved_contacts.csv 참고.

## 시스템 설계 시 반영할 것
- 연락처 레코드마다 source_url·verified_on·confidence 저장(schema.sql contacts).
- 보강 작업 큐: 번호 없는 A/B 리드부터 처리, 결과는 사람이 승인 후 반영.
- 자동 수집은 robots.txt·이용약관 준수. 차단·봇 감지 사이트는 우회하지 말고 수동 확인 큐로.
- 지자체·공공기관은 공식 대표번호/담당부서(부서명)까지만. 담당자 개인 연락처는 수집하지 않는다.
