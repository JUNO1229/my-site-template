# 준수사항
- 개인정보: 조직 단위 공개 연락처만 저장. 개인 휴대폰·개인 이메일·개인 SNS 수집 금지. 담당자 이름은 공개된 직책 수준 외 저장 금지.
- 정보통신망법(영리 목적 광고성 정보): 이메일·문자·팩스 발송은 사전 수신 동의 필요. outreach.consent_for_email 이 true 인 경우에만 발송 기능 허용. 최초 접촉은 전화·공식 문의 폼·우편 우선.
- 수신 거부 요청 시 stage = do_not_contact 로 영구 차단, 발송 큐에서 제외.
- 자동 크롤링: 약관·robots.txt 준수, 접속 차단·봇 감지는 우회하지 않는다.
- 데이터 출처 표기: 공공데이터 이용 조건(공공누리 등) 확인 후 내부용/외부용 구분.
